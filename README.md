# Spotlight Landing Page

Marketing site for [Spotlight for Windows](https://github.com/Rishiraj1729/Spotlight) — Apple-style frosted glass aesthetic, offline-first positioning.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import **Rishiraj1729/Spotlight-Landing-Page** from GitHub
3. Vercel auto-detects Vite — leave defaults:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Click **Deploy**

Every push to `main` redeploys automatically.

Or deploy from CLI:

```bash
npm i -g vercel
vercel
```
